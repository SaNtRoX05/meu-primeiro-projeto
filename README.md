
# Calculadora em Python

## Sobre o projeto
Uma calculadora simples desenvolvida em Python para realizar operações matemáticas básicas.

## Operações disponíveis
- Soma
- Subtração
- Multiplicação
- Divisão

## Como executar

Execute o seguinte comando no terminal:

```bash
python3 calculadora.py
```

Para executar com o script shell (Linux):

```bash
bash calculadora.sh
```

## Como o código funciona

O arquivo `calculadora.py` funciona em 3 etapas:

1. Mostra um menu com as operações: 1 (Soma), 2 (Subtração), 3 (Multiplicação) e 4 (Divisão).
2. Pede para o usuário escolher uma operação e digitar dois números.
3. Calcula o resultado e mostra na tela.

Se o usuário tentar dividir por zero, o programa avisa que não é possível. Se escolher uma opção que não existe, mostra "Opção inválida!".

## Tecnologias utilizadas
- Python
- Shell Script
